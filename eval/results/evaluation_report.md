## 4. Key Mechanisms Behind Measured Efficiency

1. **Negative Knowledge Suppression:**
   In the ungoverned baseline, agents repeatedly queried Kubernetes pod statuses to rule out OOM events, generating 2.8 redundant calls per case. In GroundTruth, when `LogAgent` commits a scoped negative check (`k8s_events:no_oom`), the negative registry suppresses redundant queries, cutting duplicate tool calls to 0.0.

2. **Contract-Scoped Context Projection vs. Chat History Accumulation:**
   The baseline relies on append-only transcripts that grow linearly with turns (5,708 mean tokens). GroundTruth projects compact typed facts bounded by contracts, reducing tokens by **79.4%**.

3. **Adversarial Write Gate Falsification:**
   In GroundTruth, every proposed fact passes through the 5-step Write Gate. Across all test scenarios, **15 / 15 ungrounded writes** were intercepted and quarantined before contaminating downstream reasoning.
